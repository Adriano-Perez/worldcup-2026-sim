# `apps/web/`

Next.js UI: Pre‑Bracket (frozen) + Live tracker.

## Starter files

- `app/layout.tsx` - wraps every page
- `app/page.tsx` - homepage
- `components/Navbar.tsx` - top navigation
- `components/Home.tsx` - landing section
- `components/StatCard.tsx` - reusable stat block
- `lib/site-data.ts` - small mock data file

## What to learn first

1. Edit `app/page.tsx` to change the homepage text.
2. Edit `components/Home.tsx` to change the big intro section.
3. Edit `lib/site-data.ts` to change the numbers on the page.
4. Later, add styling with Tailwind CSS.
